# Public summary of the independent Lean audit

The independent audit completed on 9 October 2026 with PASS for the stated nonpolynomial ordered binary matrix removal theorem under the reported Lean trust base. It rebuilt all 36 project modules from the frozen source using a fresh official Lean 4.34.1 macOS arm64 distribution. It checked ordinary independent increasing embeddings matching all sixteen bits, exact counting of those embeddings, actual minimum unrestricted Hamming edit distance, all-depth localization and the stronger arbitrary epsilon-dependent size-threshold theorem.

The final theorem's printed axioms are exactly `propext`, `Classical.choice` and `Quot.sound`. A separate walk of references in both declaration types and bodies reached 18,348 declarations, including 855 project declarations, with no missing or unsafe declarations and only those three axioms. The unchanged `evidence/trust-summary.json` and `evidence/trust-graph.json` give its summary and full graph. Imported opaque definitions are part of the disclosed environment; none belongs to the project.

The auditor checked the official compiler archive digest, the pinned mathlib source archive and 9,291 source hashes, eight pinned dependency trees and their Git object integrity, and all 2,022 required cache archives against fresh official downloads. Every compared official cache archive matched. This checks the origin of the imported dependency artifacts; it is not a complete rebuild of mathlib source or an independent compiler bootstrap.

The newly written independent host checker uses rational interval endpoints rather than the Lean recursive traversal. Its axes and matrix entries match Lean exports at depths 1, 2 and 3: 1,024 + 14,400 + 123,904 = 139,328 physical cells. It also exhausts depth-one ordinary copies and obtains 128. This is bounded implementation evidence. The Lean proofs supply the all-depth claims; these tests do not extend by extrapolation.

`checkers/IndependentStatements.lean` is unchanged audit source for explicit pattern, counting, Hamming minimum, nonvacuity and quantified statement checks. `checkers/compare_hosts.py` is unchanged, standalone standard-library audit code. The bundled exports are recorded outputs of the audited Lean host. Running that Python script checks them against an independent construction; generating fresh exports is a separate Lean step. These files are hashed in `ARTIFACT_MANIFEST.json`.

Remaining trust limits: the official Lean compiler and standard library, imported official mathlib binaries, standard foundational axioms, and the execution environment. The auditor did not bootstrap the compiler, rebuild all mathlib source, test another platform or obtain human peer review. Exact copy formulas, equality of repair distance, minimum pattern size and global priority are not certified. The frozen proof archive and exact original audit report remain unchanged; this public summary omits private development locations and does not claim to be the original report.
